# Северяночка — интернет-магазин продуктов

Учебный проект: сайт магазина продуктов по макету (главная, каталог, категория, товар, поиск) на **React + Express + PostgreSQL**.
Структура и стек повторяют пример `course_dxxdly`. Названия классов — только через подчёркивание (`header_nav_link`), без дефисов.

## Стек
- Frontend: React 19, Vite, react-router-dom, SCSS, шрифт Rubik
- Backend: Node.js 22, Express 5, pg, cors, dotenv
- БД: PostgreSQL (массивы `text[]`, `int[]`, JSONB, GIN-индекс)
- Если API недоступен, на страницах показываются запасные массивы из `src/data/fallback.js`

## Структура
```
db/init.sql            схема и данные (категории, товары, отзывы, магазины, статьи…)
backend/               REST API (порт 3000), настройки БД в .env
frontend/vite-project/ React-приложение (порт 5173)
docker-compose.yml     PostgreSQL в Docker
```

## Запуск
1. **База данных** — один из вариантов:
   - `docker-compose up -d` (скрипт `db/init.sql` выполнится сам);
   - либо в DBeaver подключиться к своему PostgreSQL (postgres / 1234, база `postgres`) и выполнить `db/init.sql`.
2. **Backend**:
   ```
   cd backend
   npm install
   node index.js
   ```
3. **Frontend**:
   ```
   cd frontend/vite-project
   npm install
   npm run dev
   ```
   Открыть http://localhost:5173

## Что работает
- Каталог с выпадающим меню, поиск с подсказками, категории с фильтрами (цена, наличие, подкатегории), сортировкой и пагинацией
- Карточка товара: галерея, характеристики, отзывы с гистограммой, «Похожие», «С этим товаром покупают», уведомление о снижении цены
- Вход по телефону (демо: `+7 912 345-67-89`, есть кнопка «Демо-вход»), избранное, корзина, оформление заказа, история заказов
- Настоящая карта магазинов (Leaflet + OpenStreetMap, нужен интернет), статьи, специальные предложения
- Адаптив: 1440 / 768 / 360 (на мобильном — нижнее меню, фильтр в выезжающей панели)

## Допущения
- Название магазина — «Северяночка», как в макете; фотографии продуктов взяты из макета.
- Вход только по номеру телефона (без пароля).
- Координаты магазинов на карте приблизительные (таблица `stores`, поля `lat`/`lng`) — при необходимости поправьте.
- У ряда товаров фото общие — в макете их не хватало.
